📝 PROJECT: Mini Google Translate
This is a simple graphical Python program that allows you to translate text from one language to another.
Uses the `translate` library for translation and `customtkinter` for creating the window.
🔧 INSTALLATION:
1. Install Python 3.10 or later
2. Download the files: main.py, config.py, requirements.txt
3. Install dependencies:
pip install -r requirements.txt
4. Run the program:
python main.py
📘 HOW TO USE:
1. Enter any text in the upper large field.
2. On the left, select the language in which the text is written (for example, "English (en)").
3. On the right, select the language into which you want to translate (for example, "Ukrainian (uk)").
4. Click the **"Translate"** button.
5. The translation result will appear in the lower field.
📂 PROJECT STRUCTURE:
- `main.py` – the main program file.
- `config.py` – a file with a language dictionary.
- `requirements.txt` – a list of required libraries.
