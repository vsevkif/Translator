📝 PROJECT: Mini Google Translate
This is a simple graphical Python program that allows you to translate text from one language to another.
Uses the `translate` library for translation and `customtkinter` for creating the window.
🔧 INSTALLATION:
1. Install Python 3.10 or later
2. Download the files: main.py, config.py, requirements.txt
3. Install dependencies:
pip install -r requirements.txt
4. Run the program:
python main.py
📘 HOW TO USE:
1. Let's see how you can translate text here?<br>
1.1. Enter any text in the upper large field.
  1.2. On the left, select the language in which the text is written (for example, "English (en)").
  1.3. On the right, select the language into which you want to translate (for example, "Ukrainian (uk)").
  1.4. Click the **"Translate"** button.
  1.5. The translation result will appear in the lower field.
2. There is a button at the top "Clear all"
  2.1. It clears the field where you enter the text for translation3. Next to the "Clear all" button is the "Settings" button, for general program settings, there is a toggle switch for changing the theme and    changing the interface language.
3. Next to the "Clear all" button is the "Settings" button, for general program settings, there is a toggle switch for changing the theme and changing the interface language.
  3.1. To open the settings menu, you need to click on the button.
    3.2.1. To change the theme to dark, you need to click once on the "Dark theme" toggle switch
    3.2.2 To change the theme to light, you need to click a second time on the "Dark theme" toggle switch
📂 PROJECT STRUCTURE:
- `main.py` – the main program file.
- `config.py` – a file with a language dictionary.
- `requirements.txt` – a list of required libraries.
